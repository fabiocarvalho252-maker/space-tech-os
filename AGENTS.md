NOTA DE ATUALIZAÇÃO (decisão tomada em sessão com o usuário)
==================================================

A base de código deste projeto mudou em relação ao estado original descrito
acima. Um projeto SPACE TECH bem mais avançado, construído via Lovable
(TanStack Start + React + Supabase), foi fornecido pelo usuário e adotado
como base principal, substituindo o scaffold inicial em Next.js + Prisma.

O scaffold antigo foi preservado (não apagado) em
`archive/nextjs-prisma-scaffold/` para referência/histórico.

Mudanças em relação às seções acima:

* Seção 29 (Banco de dados): em vez de PostgreSQL + Prisma direto, o projeto
  usa Supabase (Postgres + Auth + Storage + Realtime via PostgREST/GoTrue),
  self-hosted via Docker nesta mesma máquina (não Supabase Cloud).
* Stack de aplicação: TanStack Start + Vite + React 19 + Tailwind, não
  Next.js.
* As demais seções (marca, módulos, fases, segurança, responsividade,
  performance) continuam válidas e são a referência funcional do projeto.
