# aprovados/ — aprovados por você, um a um

Só entram aqui conteúdos com status **APROVADO** e com o bloco "Aprovação"
preenchido (quem aprovou, data e plataformas autorizadas).

Estar aprovado **não** significa que será publicado automaticamente: a
publicação também é feita só quando você mandar. Se o texto for alterado depois
da aprovação, o arquivo volta para `../aprovacao/`.
