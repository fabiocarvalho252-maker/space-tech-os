# CLAUDE.md

Projeto: Next.js / Node.js.

## Regras rápidas
- Use `npm` para instalar, testar e buildar.
- Antes de finalizar mudanças, rode `npm run build`.
- Mantenha as alterações mínimas e focadas na tarefa.
- Prefira editar arquivos existentes em vez de criar novos sem necessidade.
- Não mexa em `node_modules/` nem em artefatos de build.

## Fluxo sugerido
1. Ler o contexto do problema.
2. Fazer a alteração necessária.
3. Validar com `npm run build` ou o comando apropriado.
4. Resumir o que mudou.
